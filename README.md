# 범노트

안드로이드 태블릿에서 PDF를 읽고 필기하는 학습용 앱입니다. S펜 필기, 형광펜, 텍스트, 그림 삽입, 선택 편집과 편집용 백업을 지원합니다.

## 다운로드

**[범노트 1.0.11 APK 다운로드](https://raw.githubusercontent.com/beomjunchoe/study-pdf-android/main/%EB%B2%94%EB%85%B8%ED%8A%B8_1.0.11.apk)** · 약 4.7 MB · Android 6.0 이상

1. 태블릿에서 APK를 내려받아 엽니다. 설치 권한이 필요하면 Android의 안내에 따라 허용합니다.
2. 기존 범노트를 사용 중이라면 앱을 삭제하지 말고 업데이트로 설치합니다. 서명이 달라 설치되지 않으면 먼저 편집용 ZIP을 백업하고 문의해 주세요.
3. 앱에서 **자료·공유**를 열어 원하는 PDF를 불러옵니다. 이 저장소의 교재 외에도 일반 PDF를 사용할 수 있습니다.

## 필기와 보관

- S펜으로 필기하고 손가락으로 화면을 이동합니다. 필요하면 손가락 필기도 선택할 수 있습니다.
- 펜·형광펜, 빠른 색상, 굵기, 지우개, 텍스트와 선택 도구를 사용합니다. 가로·세로 화면을 지원합니다.
- **저장 중…**이 끝나고 **✓ 저장됨**을 확인한 뒤 앱을 종료합니다. 저장 실패가 표시되면 여유 공간을 확인하고 다시 저장합니다.
- 다른 앱에서 읽거나 제출할 때는 **필기를 포함한 PDF**를 내보냅니다. 계속 편집하거나 다른 기기로 옮길 때는 **편집용 ZIP 백업**을 함께 보관합니다.

PDF로 내보낸 필기는 다른 앱에서 같은 방식으로 편집할 수 있다는 뜻은 아닙니다. 앱 삭제·데이터 초기화 전에는 외부 저장소에 ZIP을 백업해 주세요. 기기 성능과 문서 특성에 따라 열기·공유·입력 동작이 달라질 수 있습니다.
